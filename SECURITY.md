# Security

## Supported versions

Only the **latest release** gets fixes. Please update before reporting a problem.

## Report a security problem privately

Please **do not** open a public issue for a security problem.

1. Go to the **[Security](https://github.com/Aishkrimmm/LuzViMinda/security)** tab of this repository.
2. Click **Report a vulnerability**.
3. Tell us:
   - the game version (shown at the bottom right of the main menu),
   - Android phone or Windows PC,
   - what the problem is and how to make it happen.

Only the team can see the report. We will reply there as soon as we can.

## What the game keeps

- **No accounts.** The game never asks for a password, email or phone number.
- **On your device only:** your player name, progress, and pre-test and post-test results. They are not sent anywhere.
- **Save files are protected:** they are scrambled (encrypted) and checked. If a save is changed or damaged, the game loads the last good copy. Restored saves and other events are listed in **Settings > PRIVACY > SECURITY LOG**.
- **Internet:** only to ask GitHub (over HTTPS) whether a newer version exists.
- **Erase everything:** **Settings > PRIVACY > DELETE MY DATA** (main menu, asks twice).

## Safe downloads

- Download the game only from the [Releases](https://github.com/Aishkrimmm/LuzViMinda/releases) page of this repository.
- Each release lists the **SHA-256** of every file. If the code of your file is different, do not install it.
- Tester builds are shared only by the team directly.
