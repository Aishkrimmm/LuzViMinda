# LuzViMinda

A gamified learning platform for Philippine history and culture: a 2D educational game for Android, made as a capstone project.

## Download (Android)

1. On your phone, open the [latest release](https://github.com/Aishkrimmm/LuzViMinda/releases/latest).
2. Under **Assets**, tap the `.apk` file. Use Chrome, and wait until the download is finished.
3. Open your **Files** app, go to **Downloads**, and tap the APK.
4. If your phone asks, allow **Install unknown apps**.
5. Open LuzViMinda and tap **New Game**.

## Updating

Download the newest APK from the same link and install it over the old one. Your progress is kept.

## If the install fails

- **"There was a problem parsing the package"**: the download did not finish. Delete the file and download it again in Chrome.
- **"App not installed"**: uninstall the old version first, then install the new one.
