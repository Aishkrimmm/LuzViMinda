# LuzViMinda Quest

A 2D educational game about Philippine history and culture, for **Android phones** and **Windows PCs**.
Travel through Luzon, Visayas and Mindanao, help the people of each place, collect lost items, and answer the Knowledge Challenges.

Made as a capstone project by the LuzViMinda Quest Team, BSIT 4-A, College of Communication and Information Technology, University of Northern Philippines (2026).

## Download

Get the newest version from the **[latest release](https://github.com/Aishkrimmm/LuzViMinda/releases/latest)**, under **Assets**:

| Device | File | Needs |
|---|---|---|
| Android phone | `LuzViMinda_vX.X.X.apk` | Android 7.0 or newer, about 300 MB free |
| Windows PC | `LuzViMinda_vX.X.X_Windows.zip` | Windows 10 or 11 (64-bit) |

Only download the game from this page. Copies from other websites are not from us.

### Install on Android

1. Open the [latest release](https://github.com/Aishkrimmm/LuzViMinda/releases/latest) in **Chrome**.
2. Under **Assets**, tap the `.apk` file and wait until the download is finished.
3. Open your **Files** app, go to **Downloads**, and tap the APK.
4. If your phone asks, allow **Install unknown apps**.
5. Open LuzViMinda Quest and tap **New Game**.

### Install on Windows

1. Download the `_Windows.zip` file.
2. Right-click it, choose **Extract All**, and open the folder.
3. Double-click **LuzViMinda Quest.exe**.
4. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. This appears because the game is not signed with a paid certificate.

### Updating

Install the new APK over the old one, or replace the old Windows folder with the new one. Your progress is kept.

### Check your download (optional)

Each release lists a **SHA-256** code for every file. On Windows, open Command Prompt in the download folder and run:

```
certutil -hashfile LuzViMinda_vX.X.X_Windows.zip SHA256
```

If the code matches the one in the release, the file is the real one.

## If the install fails (Android)

- **"There was a problem parsing the package"**: the download did not finish. Delete the file and download it again in Chrome.
- **"App not installed"**: uninstall the old version first, then install the new one.

## Privacy

- No account and no sign-in.
- Your name, progress and test results stay **only on your device**. Nothing about you is sent anywhere.
- With internet, the game only asks GitHub if there is a newer version.
- Save files are scrambled and checked, so a changed or damaged save is caught.
- To erase everything: **Settings > PRIVACY > DELETE MY DATA**.

## Report a problem

- **Bugs:** open an [issue](https://github.com/Aishkrimmm/LuzViMinda/issues/new/choose) and fill in the bug report form.
